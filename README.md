 Dette prosjektet er en samling av små, interaktive React-komponenter utviklet for å lære grunnleggende konsept
 som State management, API-håndtering, og input-validering.                                                      

Komponenter:                                                                              
1.  Cat Facts
En applikasjon som henter tilfeldige fakta om katter.

API: Bruker fetch mot catfact.ninja.

Funksjoner: Tilfeldig sidevalg, loading-indikator og feilhåndtering.

Media: Inkluderer en animert GIF (sourcat.gif) importert fra assets.

2. User Management
En enkel oversikt over brukere med mulighet for å legge til nye.

State: Bruker useState for å håndtere en liste med objekter.

Data: Starter med mockData (Ola Normann, Torleif, osv.).

Logikk: Inkluderer kontrollerte input-felter som tømmes etter at en bruker er lagt til.

3. Cookie Clicker
Et klassisk klikkerspill.

Interaksjon: Øker poengsummen hver gang brukeren klikker på kake-bildet.

Enkel State: Demonstrerer enkel numerisk oppdatering i React.
